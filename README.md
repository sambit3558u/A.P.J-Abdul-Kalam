# 🌟 A.P.J. Abdul Kalam Tribute Page

A simple and responsive tribute webpage dedicated to **Dr. A.P.J. Abdul Kalam**, the **Missile Man of India** and the 11th President of India. This project is built using **HTML5** and **CSS3** to showcase his life, achievements, and inspiring journey.

## 📖 About the Project

This is a beginner-friendly web development project that presents a tribute to Dr. A.P.J. Abdul Kalam. The webpage includes his image, a brief biography, a list of famous biographies and documentaries, and a link to learn more about him.

## ✨ Features

* Responsive and clean user interface
* Biography section
* List of books and documentaries
* Profile image of Dr. A.P.J. Abdul Kalam
* External link to Wikipedia
* Built with semantic HTML and CSS

## 🛠️ Technologies Used

* HTML5
* CSS3
