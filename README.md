# 🌟 A.P.J. Abdul Kalam Tribute Page

A simple and responsive tribute webpage dedicated to **Dr. A.P.J. Abdul Kalam**, the former President of India and one of the country's greatest scientists. This project is built using **HTML** and **CSS** to showcase his life, achievements, and inspiring journey.

## 📌 Features

- Clean and responsive layout
- Profile image of Dr. A.P.J. Abdul Kalam
- Brief biography
- List of famous biographies and documentaries
- External link to the official Wikipedia page
- Beginner-friendly HTML and CSS project

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📖 About Dr. A.P.J. Abdul Kalam

Dr. Avul Pakir Jainulabdeen Abdul Kalam (1931–2015), popularly known as the **"Missile Man of India"**, was an aerospace scientist, educator, and the 11th President of India. He made significant contributions to India's missile and space programs and inspired millions through his vision, leadership, and dedication to education.
